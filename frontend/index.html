Comment fonctionnent les Modpacks (SHA-256) ?
BMM crée une signature unique (hash) pour chaque mod. Lorsqu'un ami importe votre pack, BMM compare ces signatures avec sa bibliothèque locale pour activer exactement les mêmes versions, évitant ainsi les erreurs de versioning.

Modpacks & Partage

Les Modpacks sont des collections de mods empaquetées dans un fichier .bmp. Ils utilisent des empreintes numériques (SHA-256) pour identifier vos fichiers, ce qui permet à vos amis de retrouver exactement les mêmes versions, même s'ils ont installé leurs mods différemment.
Empreintes SHA-256
Identification unique des fichiers pour une compatibilité garantie entre joueurs, même avec des noms de dossiers différents.
Multi-Profile Support
Créez des packs contenant des mods venant de plusieurs profils BMM différents en une seule activation.
Portabilité Totale
Exportez votre configuration en un clic. Vos amis n'ont qu'à importer le fichier pour synchroniser leur jeu.

Comment créer un pack ?

  1. Allez dans l'onglet Modpacks et cliquez sur Créer.
  2. Donnez un nom et une description à votre pack.
  3. Ajoutez les mods souhaités. BMM récupérera automatiquement leurs signatures SHA-256.
  4. (Optionnel) Ajoutez des liens de téléchargement directs pour faciliter la vie de vos amis.
  5. Sauvegardez et cliquez sur Exporter pour obtenir votre fichier .bmp.

Questions fréquentes (FAQ)

Est-ce que mes mods sont conservés si je change de profil ?
Oui ! Chaque profil garde son propre état de mods. Quand vous revenez sur un profil, vos mods activés sont toujours là, même après redémarrage.
Quelle est la différence entre .MM et .JSON ?
Aucune techniquement ! .MM est simplement un fichier .JSON renommé pour faciliter le partage entre joueurs.
Que se passe-t-il si je supprime un mod activé ?

Vous devez d'abord désactiver le mod pour que ses fichiers soient retirés du jeu et les backups restaurés, puis vous pouvez le supprimer en toute sécurité.

Comment fonctionnent les Modpacks (SHA-256) ?

Les Modpacks de BMM utilisent des empreintes numériques (SHA-256) pour identifier les fichiers de mods de manière unique.

Cela permet à un utilisateur de télécharger un modpack et de l'utiliser sur n'importe quel PC : BMM reconnaîtra automatiquement si les mods sont déjà présents sur votre machine, peu importe où ils sont stockés, en comparant leur contenu.

Si des mods manquent, BMM peut les télécharger automatiquement depuis le ServerRepo s'ils y sont disponibles.

Que se passe-t-il si mon disque est plein ?

BMM vérifie l'espace avant chaque copie. Si le disque est plein, l'activation est bloquée.

Puis-je désactiver la limite de sécurité ?
Non, le blocage en cas de disque saturé est vital pour protéger vos données.
Comment obtenir un token GitHub PAT ?

Un Personal Access Token (PAT) vous permet de télécharger plus de 60 mods/heure depuis GitHub. Voici comment en créer un :

  1. Connectez-vous à github.com avec votre compte.
  2. Cliquez sur votre avatar en haut à droite → Settings.
  3. Dans le menu de gauche, descendez jusqu'à Developer settings (tout en bas).
  4. Cliquez sur Personal access tokens → Tokens (classic).
  5. Cliquez sur Generate new token (classic).
  6. Donnez-lui un nom (ex: BMM Downloads), choisissez une durée d’expiration, et cochez uniquement public_repo dans la section repo.
  7. Cliquez Generate token, copiez le token (il commence par ghp_) et collez-le dans le champ GitHub PAT des paramètres de BMM.
⚠️ Ne partagez jamais votre token ! Il donne accès à votre compte GitHub.
À quoi sert le limiteur d'E/S disque ?

Le limiteur d'E/S (entrées/sorties) permet de réduire l'impact de BMM sur les performances générales de votre PC pendant les opérations de copie ou de téléchargement, en limitant la vitesse à laquelle les données sont lues ou écrites sur le disque.

Comment créer un lien d'installation en 1-clic valide ?

Seuls les liens de téléchargement directs (DDL) sont compatibles. Un DDL lance le téléchargement immédiatement sans passer par une page intermédiaire. Les liens GitHub 'Releases' ou les liens directs vers un fichier sur un serveur privé sont parfaits.

Comment fonctionne la reprise de téléchargement ?

BMM découpe les fichiers volumineux en morceaux de 4 Mo. Si une erreur survient (coupure internet, crash ou fermeture), BMM vérifie quels morceaux sont déjà validés et ne télécharge que les parties manquantes.

Que se passe-t-il si mon disque est plein ?

BMM intègre maintenant des sécurités. Si votre espace libre descend sous le seuil d'alerte configuré, vous recevrez un avertissement. S'il descend sous le seuil critique, l'activation sera bloquée pour protéger votre système.

Comment fonctionnent les Modpacks (SHA-256) ?

Les modpacks utilisent des empreintes numériques (SHA-256) pour identifier vos mods de manière unique. Cela garantit que chaque joueur utilise exactement la même version des fichiers, même si l'arborescence des dossiers diffère.

C'est quoi le Server Repo ?

Une méthode premium pour partager des mods. Un utilisateur héberge un dépôt, et les autres se connectent via une URL pour synchroniser automatiquement leurs fichiers.

This is completely optional — BMM works without it, but helps when downloading many GitHub-hosted mods at once. Your token is stored only locally in your browser storage and never sent anywhere except GitHub.
