Guide d'utilisation de Better Mod Manager

Comment fonctionne le modding ?

Le modding consiste à modifier ou ajouter des fichiers au jeu original. Better Mod Manager simplifie ce processus en gardant vos mods séparés du jeu ("Dossier des mods"). Lorsque vous "Activez" un mod, BMM copie intelligemment les fichiers du mod dans le répertoire du jeu.

À quoi sert le dossier Backup ?

La sécurité avant tout ! Si l'activation d'un mod nécessite de remplacer un fichier original du jeu, BMM va d'abord sauvegarder l'original dans le dossier Backup que vous avez défini. Ainsi, lorsque vous désactivez le mod, le fichier original est restauré, laissant votre jeu intact.

Comprendre le format .MM

L'extension .MM a été créée pour partager facilement vos listes de mods. Sous le capot, il s'agit simplement d'un format .JSON standard. L'extension personnalisée permet à vos amis de se repérer plus facilement et de l'importer en un clic.

Comment ça marche ?

Contrairement aux gestionnaires de mods classiques qui créent des liens virtuels (symlinks) risqués ou instables, Better Mod Manager effectue une copie physique intelligente de vos fichiers.

1. Activation : Lorsque vous activez un mod, BMM analyse les fichiers. S'ils remplacent des fichiers originaux du jeu, il les copie discrètement dans votre dossier Backup. Ensuite, il injecte les fichiers du mod dans le jeu.

2. Désactivation : Lorsque vous désactivez le mod, BMM supprime les fichiers du mod du jeu, puis restaure instantanément les fichiers originaux depuis le dossier Backup. Votre jeu retrouve son état pur.

⚠️ Attention : Veillez toujours à désactiver un mod depuis l'application avant de supprimer physiquement son dossier, sinon le jeu conservera ses fichiers de modification et le backup ne sera pas restauré.

Questions fréquentes (FAQ)

Est-ce que mes mods sont conservés si je change de profil ?
Oui ! Chaque profil garde son propre état de mods. Quand vous revenez sur un profil, vos mods activés sont toujours là, même après redémarrage.
Quelle est la différence entre .MM et .JSON ?
Aucune techniquement ! .MM est simplement un fichier .JSON renommé pour faciliter le partage entre joueurs.
Que se passe-t-il si je supprime un mod activé ?
Vous devez d'abord désactiver le mod pour que ses fichiers soient retirés du jeu et les backups restaurés, puis vous pouvez le supprimer en toute sécurité.
Comment mettre à jour un mod ?
Désactivez le mod, remplacez ses fichiers dans le dossier des mods dans l'explorateur Windows, puis réactivez-le dans l'application. Le backup sera recréé automatiquement.
