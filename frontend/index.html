GitHub Personal Access Token OPTIONAL

GitHub limits unauthenticated downloads to 60 requests/hour. Adding your Personal Access Token (PAT) raises this limit to 5 000 req/hour. This is completely optional — BMM works without it, but helps when downloading many GitHub-hosted mods at once. Your token is stored only locally in your browser storage and never sent anywhere except GitHub.
