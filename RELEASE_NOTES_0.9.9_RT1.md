# Better Mod Manager 0.9.9 RT1 - Early Access

Nous sommes ravis d'annoncer la sortie en **Early Access** de **Better Mod Manager 0.9.9 RT1** !

Cette version apporte des améliorations majeures et de nouvelles fonctionnalités pour une expérience utilisateur encore plus fluide.

---

## Lancement de BMM_Web

Nous annonçons également le lancement officiel du site web de BMM : **[BMM_Web](https://freeproject089.github.io/BMM_Web/)**

Ce site permet de :
- Suivre les mises à jour de BMM sans lancer l'application
- Trouver rapidement les liens de téléchargement à jour

**Futur** : BMM_Web permettra également d'afficher la liste des Server Repos hébergés 24h/24, 7j/7.
