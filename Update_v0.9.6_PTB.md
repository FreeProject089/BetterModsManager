# 🧪 Welcome to the Public Test Build!

You are running a **pre-release** version of Better Mod Manager. Features listed below are under active development and may behave unexpectedly. Your feedback helps us ship a stable release.

## What's new in PTB v0.9.6

### 🔄 Auto-Update System
BMM now checks for new versions automatically.
- **Startup check** — Silently queries GitHub on launch. You'll only be notified if an update exists.
- **Manual check** — New green button in the sidebar footer for on-demand verification.
- **Settings toggle** — Enable or disable automatic checks from the Settings page.
- **Update modal** — Shows version comparison, release notes, and a direct download link.

### 🛡️ Profile Deletion Safety
- Profiles with **active mods** can no longer be deleted without disabling them first.
- BMM will prompt you and offer to disable all active mods before proceeding.

### 🧪 PTB Mode
- A welcome modal (this one!) now greets PTB testers on each session.
- Controlled via `app.cfg` — set `PTB=true` to activate.
