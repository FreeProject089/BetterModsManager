# v0.9.7 — PTB Release Notes

> **Public Test Build** — March 2026

This PTB focuses on performance, reliability, and internationalization.

---

## Refactoring & Performance
- **Instant Mod Detail Loading** — The mod detail panel now renders immediately with stored information. Conflict checks and file verification are deferred to a background async worker.
- **Optimized Conflict Engine** — Selective conflict checking now only processes enabled mods or the currently selected mod. This significantly improves responsiveness during mod activation.
- **Frontend Modularization** — The JavaScript codebase has been refactored into distinct modules (`api.js`, `components.js`, `utils.js`, `state.js`) for better maintainability and performance.

## Improvements & Features
- **Dynamic Language Discovery**: BMM now automatically detects any `.json` file added to the `frontend/Lang` folder.
- **Enhanced Language UI**:
    - **Unified Selector**: The settings page now features a clean, single dropdown for language selection.
    - **FlagCDN Integration**: High-quality country flags are now rendered using FlagCDN for a more premium look.
    - **Smart Fallback**: Offline support ensures flags show as stylized text if no internet connection is available.
- **Automated Version & Build System**:
    - **Static Build Date**: Captures the exact compilation date using a Rust build script.
    - **Dynamic Injection**: Version and build date are automatically injected across all UI components (Credits, Footer, Titlebar).
- **Intelligent PTB Badging**: The "-PTB" suffix and blue version badge now adapt dynamically based on the application's actual configuration.
- **Improved Translation System**: Completely translatable settings interface and updated Translation Guide.
- **New Translation**: Basic German (de.json) support added.

## Public Test Build (PTB) Objective
The goal of this PTB is to gather feedback and identify bugs before the final release. 
Please report any issues or suggestions on our Discord! Your feedback is essential to making BMM the best possible experience.

## Technical Changes
- Moved all hardcoded version strings to dynamic placeholders.
- Robust Rust-side Lang directory detection for both dev and prod environments.
- Optimized mod detail rendering for instant appearance.
- Color-coded priority indicators in .MM Lists and priority values on hover.
- **Safety First** — Improved integrity checks during mod activation to ensure game files are properly backed up before being overwritten.
