# 🧪 Welcome to the Public Test Build (PTB)!

You are currently using a test version of **Better Mod Manager**. This version contains features under development that may be unstable.

## 🌟 What’s new to test in this PTB (v0.9.6):

### 🔄 Auto-Upgrade System
The update manager has been completely overhauled.
*   **Automatic verification**: No more need to monitor GitHub.
*   **Manual button** : A new option in the sidebar to check for updates on demand.
*   **Total control**: Disable the auto-updater in settings if you prefer the manual method.

### 🛡️ Digital Signature v1
All future updates will now be digitally signed to ensure that no one has modified the files you are installing.
